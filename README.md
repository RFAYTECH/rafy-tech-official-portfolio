# RAFY TECH — Portfolio

A responsive, single-page personal portfolio with a futuristic cybersecurity and coding aesthetic.

## Preview locally
1. Download or clone this repository.
2. Open `index.html` in a browser.

No build tools or package installation are required.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation and scroll reveal
- `assets/` — supplied profile and gallery photos

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload all files and folders from this project (keep the `assets` folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Personalize before publishing
- Replace the sample email address `hello@rafytech.example` in `index.html` with an email address you want visitors to use.
- Add real social profile links if you want them shown.
- The site intentionally uses only the brand name **RAFY TECH**; no individual friend names are displayed.

## Photo notes
The profile photo is used in the hero section. The two additional photos are used in the gallery. Make sure you have permission from everyone pictured before publishing their photos publicly.

## Safety and accuracy
The portfolio describes cybersecurity and ethical hacking as interests and learning goals, not as professional credentials. Practice security testing only on systems you own or have explicit permission to test.
